## Projects

**[Sightline](https://github.com/dangkhoipham80/sightline)** — *Stop vibing blind.*<br />
A clear line of sight into every Claude Code session, across every project. The memory &amp; review layer that turns raw `*.jsonl` session logs into something you can actually read.<br />
<sub>TypeScript · Node.js · Claude Code</sub>

**JobPilot** — *CV autopilot, on your own machine.*<br />
Crawl developer jobs → review them on a local dashboard → tailor your CV to one → approve the diff → apply → track what comes back. Built on the Awesome-CV LaTeX template.<br />
<sub>Python · PostgreSQL · Docker · LaTeX</sub>

**Hunter Haven** <sub>(working title)</sub> — [play the demo ↗](https://hunter-haven.hunterhaven.workers.dev)<br />
An idle town-sim for the web, inspired by Evil Hunter Tycoon. Plays in a phone browser and installs like an app (PWA).<br />
<sub>TypeScript · React 19 · PixiJS · Vite · PWA</sub>

**Portfolio** — *A full-stack app, not a static site.* — [khoipham.vercel.app ↗](https://khoipham.vercel.app)<br />
Monorepo personal site: a Next.js web app talking to a real FastAPI backend with migrations and a hosted Postgres. Content lives in the database, not in hardcoded arrays.<br />
<sub>Next.js 16 · React 19 · Tailwind v4 · FastAPI · Neon Postgres</sub>
